# Gerador de jogos do bolão

Página que gera jogos para a **Mega da Virada** e a **Lotofácil** com estratégias baseadas no histórico oficial de sorteios da Caixa.
Abra em: https://marcelokielwagen.github.io/bolao-virada/

É sorteio: nenhuma estratégia muda a chance de uma combinação sair. A página só gera os números; a aposta é feita por você.
Estudo independente, sem vínculo com a Caixa. Desenvolvido por Claude Opus 5.5.
