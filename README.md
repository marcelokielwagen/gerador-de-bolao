# Gerador de Bolão

Página que gera jogos de bolão para a **Mega-Sena** (qualquer concurso, inclusive a Virada) e a **Lotofácil**, com estratégias testadas no histórico oficial de sorteios da Caixa.
Abra em: https://marcelokielwagen.github.io/gerador-de-bolao/

É sorteio: nenhuma estratégia muda a chance de uma combinação sair. A página só gera os números; a aposta é feita por você.
Estudo independente, sem vínculo com a Caixa. Desenvolvido por Claude Opus 5.5.
